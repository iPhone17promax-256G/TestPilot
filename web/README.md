# TestPilot 前端

Vue 3 + TypeScript + Vite + CodeMirror。已接真实 API；不使用示例数据或 localStorage 模拟成功。

整体启动见 [项目 README](../README.md)。前端单独开发时，先在仓库根目录启动后端，生成本次安装的 HTTPS 证书：

```bash
bash scripts/start.sh --local
```

首次使用必须按项目 README 的“HTTPS 与本地证书”说明，在浏览器所在系统信任 `.tls/rootCA.pem`。Windows 浏览器和 WSL 的信任库不同；信任操作由用户完成，启动脚本不会自动修改系统信任。证书与私钥仅留在本机，不提交 Git。

然后启动前端：

```bash
cd web
npm ci
npm run dev
```

需要 Node.js 22.6 及以上。开发地址为 **https://127.0.0.1:5173**，预览为 **https://127.0.0.1:5174**，两个服务只监听本机。它们使用 `.tls/platform.pem` 与 `.tls/platform-key.pem` 提供 HTTPS，并使用 `.tls/rootCA.pem` 校验代理后端 **https://127.0.0.1:8020** 的证书；不会关闭证书校验，也不会回退 HTTP。证书缺失时会提示先完成整体启动。若使用其他证书目录，启动前设置 `TESTPILOT_TLS_DIR`。

`/api`、`/mcp` 由开发服务代理，保留浏览器请求的 Host，使登录 Cookie 和后端同源检查在开发环境仍然有效。生产文件由 API 提供，使用 `npm run build` 同时进行类型检查和构建；静态构建不要求存在本机证书。

`npm test` 检查实际 Markdown 渲染器的 HTML／图片说明转义与危险链接处理。包括数据库和执行器的完整检查使用项目根目录的 `python3 scripts/check.py`，会创建并清理独立测试数据库。

六个入口：Agent 工作台、测试用例、运行记录、应用与设备、项目与环境、设置。前端显示后端状态，不负责判定测试通过。轮询不会覆盖编辑器中未保存的代码，保存后会重新读取服务器的新版本。

界面结构：

- Agent 以连续对话呈现，每次回复的执行过程可展开查看工具参数和结果；相关用例、报告和页面观察在结果面板查看。
- 可视化编辑器左侧排列步骤，右侧编辑当前步骤。请求参数、请求体、断言与高级选项分开；动作选择器支持搜索和控制块内插入。未完成字段断言会提示补全并阻止保存。
- 用例和运行列表支持筛选、分页，返回列表保留本项目的筛选。报告先展示失败位置与原因，再提供步骤、截图、日志和执行版本源码。
- 性能负载阶段使用表单，失败率填写百分比。RPS、响应时间和用户数各用实际单位显示；单采样点不画成趋势。
- 设备与应用版本分标签管理，设备行可直接打开观察窗口。设置中的“工具接入”用于为 TestPilot 添加 MCP，“对外接入”用于给其他 Agent 使用 TestPilot。

布局适配桌面和窄屏，支持收起侧栏；窄屏的导航、会话和结果使用抽屉，表格横向滚动。浏览器开发验收只使用真实 Chrome extension，禁用内嵌浏览器。
